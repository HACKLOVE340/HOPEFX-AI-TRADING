# HOPEFX AI Trading Platform — Optional Dependencies
#
# These packages require system libraries, have platform restrictions, or are
# heavy GPU/ML deps NOT installed by default. Install manually after satisfying
# the system prerequisites listed for each group.
#
# DO NOT add these to requirements.txt — they are intentionally optional.
# All code that uses these packages is guarded with try/except ImportError.

# ── PyTorch ───────────────────────────────────────────────────────────────────
# Required by: sentence-transformers, stable-baselines3, ml/models/lstm.py
# Install via the official index for the correct CUDA version:
#   CPU:  pip install torch --index-url https://download.pytorch.org/whl/cpu
#   CUDA: pip install torch --index-url https://download.pytorch.org/whl/cu121
# torch>=2.1.0

# ── TensorFlow ────────────────────────────────────────────────────────────────
# Required by: ml/models/lstm.py, enhanced_ml_predictor.py (guarded)

# tensorflow>=2.16.0
