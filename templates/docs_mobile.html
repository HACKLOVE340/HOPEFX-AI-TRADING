Mobile Guide

HOPEFX is fully accessible from mobile browsers. This guide covers setup, key features, and tips for trading on the go.

Getting Started on Mobile

1

Open in your mobile browser

Navigate to your HOPEFX instance URL in Chrome (Android) or Safari (iOS). The platform is fully responsive and adapts to any screen size.

2

Add to Home Screen

iOS (Safari): Tap the Share button → "Add to Home Screen".
Android (Chrome): Tap the menu (⋮) → "Add to Home Screen".
This creates a PWA-like shortcut with full-screen mode.

3

Log in

Use your email and password at /login. Enable biometric login (Face ID / fingerprint) via your browser's credential manager for faster access.

4

Enable Push Notifications (optional)

When prompted, allow notifications to receive real-time signal alerts, kill switch events, and price alerts directly on your device.

Mobile Features

Live Price Feed

Real-time XAUUSD bid/ask via WebSocket. Updates every tick without page refresh.

Signal Alerts

Push notifications for new AI signals, including direction, confidence, and entry price.

One-Tap Orders

Place market orders with pre-configured lot size and risk parameters in a single tap.

Position Monitor

View open positions, unrealised P&L, and close individual trades from the positions panel.

Kill Switch

Emergency stop button accessible from the main navigation. Halts all trading instantly.

Account Summary

Balance, equity, margin level, and daily P&L at a glance from the dashboard.

Performance Tips

Use Wi-Fi or a stable 4G/5G connection for live trading. WebSocket connections may drop on weak signals, causing delayed price updates.
  • Keep the browser tab active — background tabs may throttle WebSocket connections on iOS.
  • Disable battery saver mode when actively trading to prevent CPU throttling.
  • Clear browser cache if charts or prices appear stale.
  • Use landscape orientation for a better chart view on smaller screens.

Security on Mobile

Never trade on public Wi-Fi without a VPN. Your access token is stored in localStorage — do not use shared or public devices.
  • Enable 2FA from Account Settings → Security for an extra layer of protection.
  • Tokens expire after 15 minutes of inactivity. You will be prompted to re-authenticate.
  • Use your browser's built-in password manager or a dedicated app (1Password, Bitwarden) to store credentials securely.
  • Log out when done, especially on shared devices: tap your avatar → Log Out.

Troubleshooting

Prices not updating

The WebSocket connection may have dropped. Pull down to refresh the page, or tap the reconnect button in the status bar.

Login loop / token errors

Clear site data: Settings → Privacy → Clear Browsing Data → Cookies and Site Data. Then log in again.

Charts not rendering

Ensure JavaScript is enabled. Some ad blockers interfere with WebSocket connections — whitelist the HOPEFX domain.

Notifications not arriving

Check that notifications are allowed for the site in your device's Settings → Notifications. On iOS, notifications require the site to be added to the Home Screen first.

API Access from Mobile

The full REST API is accessible from mobile apps and scripts. See the API Reference for endpoint details. Use POST /api/auth/login to obtain a token, then include it in all requests: 

Authorization: Bearer <access_token>
