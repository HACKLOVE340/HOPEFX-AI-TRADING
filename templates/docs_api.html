API Reference

The HOPEFX REST API is built on FastAPI. All endpoints return JSON. Interactive documentation is available at /docs (Swagger UI) and /redoc (ReDoc).

Authentication

All protected endpoints require a Bearer JWT token in the Authorization header:

Authorization: Bearer <access_token>

Obtain a Token

POST /api/auth/login
Returns access_token and refresh_token.
{
  "email": "user@example.com",
  "password": "your_password"
}

Response:

{
  "access_token": "eyJ...",
  "refresh_token": "eyJ...",
  "token_type": "bearer",
  "user": { "id": 1, "email": "user@example.com", "role": "trader" }
}

Refresh Token

POST /api/auth/refresh
Exchange a refresh token for a new access token.

Register

POST /api/auth/register
Create a new user account.
{
  "email": "user@example.com",
  "password": "StrongPass123!",
  "first_name": "Jane",
  "last_name": "Doe"
}

Trading

GET /api/trading/account
Current account balance, equity, margin, and open P&L.
GET /api/trading/positions
All open positions with entry price, size, and unrealised P&L.
POST /api/trading/order
Place a market or limit order.
{
  "symbol": "XAUUSD",
  "side": "buy",
  "units": 1000,
  "order_type": "market",
  "stop_loss": 2300.00,
  "take_profit": 2380.00
}
DELETE /api/trading/position/{trade_id}
Close a specific position by trade ID.
GET /api/trading/price/{symbol}
Current bid/ask price for a symbol.

Signals

GET /api/signals/latest
Latest AI-generated trading signal with confidence and regime.
GET /api/signals/history
Historical signals with outcomes. Query params: limit, symbol.

Risk

GET /api/risk/metrics
Current risk metrics: VaR, CVaR, drawdown, Sharpe ratio.
POST /api/kill-switch/activate
Immediately halt all trading. Propagates to all pods.
POST /api/kill-switch/deactivate
Re-enable trading after kill switch activation.

Health

GET /api/health
Overall system health. Returns 200 when all critical components are up.
GET /api/health/startup
Kubernetes startup probe. Returns 200 once startup is complete.
GET /api/health/ready
Kubernetes readiness probe.

WebSocket

WebSocket connections require the access token as a query parameter: ?token=<access_token>
WS /ws/live
Real-time price ticks, signals, and position updates.
WS /ws/nuclear
Nuclear dashboard chart engine stream.

Rate Limits

  • Auth endpoints: 10 requests / 60 seconds per IP
  • Trading endpoints: 60 requests / minute per user
  • Signal endpoints: 120 requests / minute per user
  • Exceeded limits return HTTP 429 Too Many Requests

Error Codes

  • 400 — Bad request / validation error
  • 401 — Missing or invalid token
  • 403 — Insufficient permissions
  • 404 — Resource not found
  • 429 — Rate limit exceeded
  • 503 — Service temporarily unavailable (broker offline, kill switch active)
