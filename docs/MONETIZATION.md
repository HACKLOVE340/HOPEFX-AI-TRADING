### Stripe Integration

The platform uses Stripe for card payments and subscription management.
Webhook events handled in `monetization/stripe_integration.py`:

| Event | Action |
|-------|--------|
| `payment_intent.succeeded` | Activate subscription |
| `payment_intent.payment_failed` | Send payment failure alert |
| `checkout.session.completed` | Provision access |
| `customer.subscription.created` | Create licence key |
| `customer.subscription.updated` | Update feature gates |
| `customer.subscription.deleted` | Suspend access |
| `invoice.paid` | Generate PDF invoice |
| `invoice.payment_failed` | Start dunning sequence |

Configure Stripe:
```bash
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_PUBLISHABLE_KEY=pk_live_...
```

### Subscription Management

```python
from monetization import SubscriptionManager

manager = SubscriptionManager()

# Create new subscription (payment required)
subscription = manager.create(
    user_id='user_123',
    plan='professional',   # $4,500/month
    billing_cycle='monthly',  # or 'annual' for 2 months free
    payment_method='card'
)

# Upgrade plan (immediate, prorated)
manager.upgrade(
    subscription_id=subscription.id,
    new_plan='enterprise',  # $7,500/month
    prorate=True            # Credit unused portion of current period
)

# Downgrade plan (effective next billing cycle)
manager.downgrade(
    subscription_id=subscription.id,
    new_plan='starter'      # $1,800/month
)

# Cancel subscription (access until end of paid period)
manager.cancel(
    subscription_id=subscription.id,
    at_period_end=True,
    reason='optional feedback'
)
```

### License Validation

```python
from monetization import LicenseManager

license_manager = LicenseManager()

# Validate license on startup
is_valid = license_manager.validate(
    license_key='HOPEFX-PRO-A7B9C2D4-X8Y2',
    machine_id=get_machine_id(),
    user_id='user_123'
)

if not is_valid:
    print("Invalid, expired, or unpaid license")

status = license_manager.get_status(user_id='user_123')
```

### Feature Gating

Features are enforced at the API layer via `require_plan` in `monetization/subscription.py`:

```python
from monetization.subscription import require_plan

@router.post("/api/ml/retrain")
@require_plan("elite")          # Elite only
async def retrain_model(...): ...

@router.get("/api/ml/predict/{symbol}")
@require_plan("professional")   # Professional and above
async def ml_predict(...): ...

@router.get("/api/signals/latest")
@require_plan("starter")        # All paid plans
async def get_signal(...): ...
```

Requests exceeding plan limits return `403 Forbidden` with `error_code: PLAN_LIMIT_EXCEEDED`.

## Security & Compliance

### Payment Security

- **PCI DSS Level 1** compliance via Stripe
- **256-bit SSL/TLS** encryption on all payment endpoints
- **No card data** stored on HOPEFX servers — tokenisation via Stripe
- **3D Secure** authentication for card payments
- **Webhook signature verification** — HMAC-SHA256 on all Stripe events (`monetization/stripe_integration.py`)

### License Protection

- Hardware fingerprinting (machine ID binding)
- Online licence validation (daily check-in)
- Device limit enforcement per tier (1/3/5/10/unlimited)
- Grace period: 7 days for payment issues before suspension
- Anti-piracy measures & DMCA protection

### Data Protection

- **GDPR** compliant — right to erasure, data portability
- **SOC 2 Type II** certification (in progress)
- End-to-end encryption for API keys and credentials
- Regular security audits (quarterly)
- Data residency options: US, EU, Asia (Enterprise & Elite)
