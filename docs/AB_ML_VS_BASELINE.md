# A/B: Does the ML beat the rule baseline?

**Question.** The decision engine runs a rule-based signal (Phase 1) and then an
ML "enrichment" (Phase 2). Until now nobody had measured whether Phase 2 actually
adds value over Phase 1 on the *same* out-of-sample bars. `ml/ab_baseline.py`
answers it.

**Method.** Build the production feature matrix + target on 40 years of XAUUSD
daily data (`data/XAUUSD_40Y.csv`), carve a **leakage-safe** OOS window (the tail,
with the label horizon purged at the boundary — see the CV-leakage fix in
`ml/train_advanced.py`), then on that identical OOS set compare:

- **baseline** — a transparent EMA20-vs-EMA50 trend rule (representative of the
  technical-indicator consensus Phase 1 votes on),
- **ml** — a calibrated XGBoost trained on the in-sample window (same pipeline as
  `oos_eval_advanced`),
- **ml_as_filter** — baseline trades taken only when the ML agrees (ML as a
  veto/confirmation layer).

Reproduce:

```bash
python ml/ab_baseline.py --csv data/XAUUSD_40Y.csv --horizon 5 --oos-years 3
```

## Result (horizon=5, OOS = 756 daily bars)

| Strategy        | Directional accuracy | Trade Sharpe | Trades | Notes |
|-----------------|---------------------|--------------|--------|-------|
| Rule baseline   | 58.3%               | 3.10         | 756    | EMA20/50 trend |
| **ML**          | **61.4%**           | **4.42**     | 756    | calibrated XGBoost |
| ML as filter    | **62.3%**           | 4.68         | 605    | 80% agreement with baseline |

**ML accuracy lift: +3.0pp. Verdict: ML adds real value.**

The ML beats the rule baseline by ~3 percentage points of directional accuracy
and improves risk-adjusted return. The best configuration is **ML-as-filter** —
take the baseline trade only when the ML agrees (it abstains on the ~20% of bars
where they disagree, which are disproportionately the losers).

## Honest caveats

- **Sharpe numbers are directional, gross, daily-bar.** No transaction costs,
  spread, or slippage are modeled, and daily-bar directional Sharpes are
  structurally higher than realistic per-trade Sharpes. Treat the **relative**
  comparison (ML vs baseline) as the signal, not the absolute Sharpe level. The
  credible deployment numbers remain the OOS accuracy + binomial p-value gates in
  `ml/train_advanced.py` and the trade-level Sharpe gate.
- **Single OOS window, single symbol (XAUUSD), single horizon (5).** This is one
  fold, not a distribution. The walk-forward CV (now leakage-purged) is the
  multi-fold view.
- **The baseline is deliberately simple.** A better-tuned rule set would narrow
  the gap; the point is to isolate the ML's *marginal* contribution, not to
  strawman the rules.

## Takeaway

Phase 2 (ML) is earning its place: it is not just decoration over the rules — it
adds a measurable directional edge, and using it as a confirmation filter on the
rule signal is the strongest of the three configurations. This justifies further
investment in the model (regime-specialized models, meta-labeling) rather than
discarding it for rules alone.
