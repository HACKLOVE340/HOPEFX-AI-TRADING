# Outcome 0020 — The decision ledger is a second artefact, not an amendment

- Decision: 0020
- Status: pending
- Review by: 2026-12-13

## Expected

"How did 0014 turn out?" becomes a question with a file to open and a falsifiable
answer. Costs a second file per decision. The ledger's own honesty stays
measurable — `adr.py --check` prints the observed/pending split, and a test
asserts observed outnumbers pending, so back-filling placeholders cannot close
the finding.

## Actual outcome

Too early for the thing this record is actually betting on — that people come
back and write outcomes when a decision is *old*, not only when the ledger is
being built.

What can be recorded already is the back-fill itself. Writing eighteen entries on
2026-09-13 surfaced **two decisions that were recorded and never applied**:

* **0014** — the nightly `slow`/`e2e` tier does not exist. No workflow runs those
  210 tests on any schedule.
* **0016** — the registry re-subjecting was never made. `docs/REGISTRY.toml` still
  reads `subject = "architecture"` and the contested count is still 3, not 0.

Both were four days old. Neither was visible from the registry, and both were one
command away from being visible the whole time.

Immutability was not touched: `docs/decisions/outcomes/` is a subdirectory, and
`records()` globs non-recursively, so outcome files are never parsed as decision
records and `immutability_problems` never sees them. That is asserted in
`tests/unit/test_adr_outcome_ledger.py::TestImmutabilityIsUnchanged` rather than
left to the glob's shape.

## Lessons

Provisional. The one already visible: **an outcome section is only useful if its
`## Expected` half is something a reader can go and test.** The two findings above
came from restating an expectation as a number and then running the command —
"3 to 0" and "runs nightly" were both checkable in seconds, and both were false.
Where an expectation was prose, the entry was correspondingly weaker.

Review whether the mechanism survives contact with an old decision, an overdue
review, and someone who did not write the original record.
