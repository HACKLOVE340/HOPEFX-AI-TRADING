# Outcome 0002 — Commit model artefacts and the built dashboard

- Decision: 0002
- Status: observed
- Observed: 2026-09-13

## Expected

A reproducible deployment and a served UI byte-identical to the tested one, paid
for with repository size and unreadable diffs on rebuilt assets. The stated
safeguard was: *"Whitelist in `.gitignore`, verify checksums in CI."*

## Actual outcome

The first half worked. 37 files under `ml/saved_models/` and 10 under
`dashboard/dist/` are tracked, and the server serves the UI with no build step.

**The safeguard did not.** `ci.yml:398` runs `python -m ml.verify_model`, which
verifies the sha256 of the single *active* model named in `registry.json` —
nothing else. `ml/saved_models/model_checksums.json`, the 12-entry manifest that
`ml/__init__.py::_verify_checksum` reads on **every** model load and is
fail-closed in production, was read by no workflow and no hook at all.

So it drifted, and nobody could see it. Traced on 2026-09-13 (finding A8): the
manifest has one commit in its entire history, and at that commit the artifacts
already hashed to something else. It never described any committed version of
those files. Two artifacts — `feature_scaler.pkl` and `stacking_ensemble.pkl` —
therefore failed integrity and **did not load in production**, silently, for the
manifest's whole life, while `python -m ml.verify_model` exited 0 because it was
not looking at them.

## Lessons

"Verify checksums in CI" was true as a sentence and false as a control. One
artifact was verified; the decision's reader would reasonably hear *the
artifacts*. When a record names a safeguard, the safeguard's **scope** is part of
the decision and belongs in the record — `verify_model` checking one file is a
different trade from it checking thirty-seven.

The second lesson is sharper and is the `hopefx-dead-controls` shape: the
manifest that *was* load-bearing was the one nothing tested, and its failure mode
was silence. `_try_load` returned `None` identically for "absent" and "integrity
refused", so even the caller could not tell a missing model from a rejected one.
A committed artefact is only as reproducible as the check that proves it is the
one you committed.
