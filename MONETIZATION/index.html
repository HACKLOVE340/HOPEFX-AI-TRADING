    HOPEFX Monetization Guide¶

    Premium AI-Powered Trading Platform — Professional Trading Solutions Last updated: 2026-07-14 | Version: 1.17

    Overview¶

    HOPEFX is a premium paid platform offering enterprise-grade AI trading solutions.

    This is NOT a free application. Payment is required to access the full platform. After the 14-day free trial, you must subscribe to one of our paid plans to continue using HOPEFX.

    This guide covers: - 14-Day Free Trial — Evaluate before subscribing - Premium Subscription Tiers — $1,800 to $10,000/month (2 months free on annual billing) - Commission Structure — Per-trade commission rates per tier - Strategy Marketplace — Buy and sell institutional-grade strategies - Premium Services — ML training, signal service, managed trading - Partnership Programs — Affiliate, reseller, white-label, educator - Payment & Billing — All accepted methods and subscription management - License & Access Control — Hardware fingerprinting, feature gating - Implementation Guide — Phase-by-phase setup with code examples - Revenue Projections — Year 1–3 growth scenarios

    Pricing Tiers¶

    Trial Period¶

    Price: FREE for 14 days only

    Features: - ✅ Paper trading only (limited to 50 trades) - ✅ 1 basic strategy - ✅ Basic charting - ✅ Single broker connection (demo account only) - ✅ Community support (email only, 72-hour response) - ✅ 1.0% commission on simulated trades - ❌ Live trading - ❌ ML prediction models - ❌ Advanced strategies - ❌ Full backtesting - ❌ API access - ❌ News integration - ❌ Pattern recognition

    Duration: 14 days — no extensions granted

    Target: Evaluation and testing only

    ⚠️ After the 14-day trial, payment is required. No free tier exists beyond the trial period.

    Starter Tier¶

    Price: - $1,800/month - $18,000/year (2 months free — save $3,600)

    Commission Rate: 0.5% per trade

    Target: Individual professional traders starting automation

    Professional Tier¶

    Price: - $4,500/month - $45,000/year (2 months free — save $9,000)

    Commission Rate: 0.3% per trade

    Features: - ✅ Everything in Starter - ✅ Multi-broker support (up to 3 accounts) - ✅ 7 advanced strategies - ✅ ML prediction models (XGBoost ensemble, 176 features, 66.4% OOS accuracy) - ✅ Unlimited backtesting (50-year data, walk-forward, Monte Carlo) - ✅ Pattern recognition engine - ✅ Priority support (24-hour response) - ✅ Full REST API access (108 endpoints) - ✅ Custom indicators - ✅ VPS hosting included - ✅ Weekly performance reviews - ✅ Social trading (leaderboard, copy trading, signal feed) - ✅ Grafana dashboards (4 dashboards, 27 panels) - ✅ Trade journal & analytics - ✅ 3 team user seats - ❌ News RAG integration - ❌ Custom ML model development - ❌ White-label options - ❌ Dedicated support manager

    Strategy Marketplace¶

    For Strategy Sellers¶

    Earn by selling your strategies on the HOPEFX marketplace:

    Step 1 — Submit - Upload strategy code (Python, BaseStrategy interface) - Provide backtesting results (minimum 12 months, walk-forward validated) - Set pricing: one-time or monthly subscription

    Step 2 — Review - Code quality & security audit (automated + manual) - Performance validation: minimum 55% win rate, Sharpe > 1.0 - Risk metrics verification: max drawdown < 20%

    Step 3 — Earn - 70% revenue share for sellers - Monthly payouts (minimum $500 threshold) - Real-time dashboard: sales, revenue, ratings

    Marketplace Pricing Guidelines:

    Strategy Type One-Time Monthly Subscription
    Basic/Starter $499–$999 $99–$199
    Advanced $1,499–$2,999 $299–$499
    Premium/ML $5,000+ $999+

    Stripe Integration¶

    The platform uses Stripe for card payments and subscription management. Webhook events handled in monetization/stripe_integration.py:

    Event Action
    payment_intent.succeeded Activate subscription
    payment_intent.payment_failed Send payment failure alert
    checkout.session.completed Provision access
    customer.subscription.created Create licence key
    customer.subscription.updated Update feature gates
    customer.subscription.deleted Suspend access
    invoice.paid Generate PDF invoice
    invoice.payment_failed Start dunning sequence

    Configure Stripe: 

    STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_PUBLISHABLE_KEY=pk_live_...

    Subscription Management¶

    from monetization import SubscriptionManager

manager = SubscriptionManager()

# Create new subscription (payment required)
subscription = manager.create(
    user_id='user_123',
    plan='professional',   # $4,500/month
    billing_cycle='monthly',  # or 'annual' for 2 months free
    payment_method='card'
)

# Upgrade plan (immediate, prorated)
manager.upgrade(
    subscription_id=subscription.id,
    new_plan='enterprise',  # $7,500/month
    prorate=True            # Credit unused portion of current period
)

# Downgrade plan (effective next billing cycle)
manager.downgrade(
    subscription_id=subscription.id,
    new_plan='starter'      # $1,800/month
)

# Cancel subscription (access until end of paid period)
manager.cancel(
    subscription_id=subscription.id,
    at_period_end=True,
    reason='optional feedback'
)

    Billing Cycles & Discounts¶

    Annual billing gives 2 months free (16.67% discount — ANNUAL_DISCOUNT = 0.1667 in pricing.py):

    Plan Monthly Yearly Annual Savings

    Professional $4,500 $45,000 $9,000 (16.67%)
    Enterprise $7,500 $75,000 $15,000 (16.67%)

    Payment Terms: - 14-Day Free Trial — Evaluate the platform before subscribing (no payment required during trial) - Payment Required — After trial, subscription payment required for continued access - Monthly: Billed on the 1st of each month - Annual: Full payment upfront (2 months free applied automatically) - Auto-renewal enabled by default - 7-day grace period for failed payments before access is suspended

    License Validation¶

    from monetization import LicenseManager

license_manager = LicenseManager()

# Validate license on startup
is_valid = license_manager.validate(
    license_key='HOPEFX-PRO-A7B9C2D4-X8Y2',
    machine_id=get_machine_id(),
    user_id='user_123'
)

if not is_valid:
    print("Invalid, expired, or unpaid license")
    print("Please renew your subscription at hopefx.com/billing")
    exit(1)

# Check subscription status
status = license_manager.get_status(user_id='user_123')
# Returns: active | expired | cancelled | past_due | trial | suspended

    Feature Gating¶

    Features are enforced at the API layer via require_plan in monetization/subscription.py:

    from monetization.subscription import require_plan

@router.post("/api/ml/retrain")
@require_plan("elite")          # Elite only
async def retrain_model(...): ...

@router.get("/api/ml/predict/{symbol}")
@require_plan("professional")   # Professional and above
async def ml_predict(...): ...

@router.get("/api/signals/latest")
@require_plan("starter")        # All paid plans
async def get_signal(...): ...

    Requests exceeding plan limits return 403 Forbidden with error_code: PLAN_LIMIT_EXCEEDED.
