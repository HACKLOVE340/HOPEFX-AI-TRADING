    Overview¶

    HOPEFX is a premium paid platform offering enterprise-grade AI trading solutions.

    ⚠️ This is NOT a free application. Payment is required to access the full platform. After the 14-day free trial, you must subscribe to one of our paid plans to continue using HOPEFX.

    This guide covers: - 14-Day Free Trial — Evaluate before subscribing - Premium Subscription Tiers — $2,000 to $10,000/month (15% discount for annual billing) - Strategy Marketplace — Buy and sell institutional-grade strategies - Premium Services — ML training, signal service, managed trading - Partnership Programs — Affiliate, prop firm, educator - Payment & Billing — All accepted methods and subscription management - Revenue Projections — Year 1–3 growth scenarios - Implementation Roadmap — Phase 1–3 rollout

    Strategy Marketplace¶

    For Strategy Sellers¶

    Earn by selling your strategies on the HOPEFX marketplace:

    Step 1 — Submit - Upload strategy code (Python, BaseStrategy interface) - Provide backtesting results (minimum 12 months, walk-forward validated) - Set pricing: one-time or monthly subscription

    Step 2 — Review - Code quality & security audit (automated + manual) - Performance validation: minimum 55% win rate, Sharpe > 1.0 - Risk metrics verification: max drawdown < 20%

    Step 3 — Earn - 70% revenue share for sellers - Monthly payouts (minimum $500 threshold) - Real-time dashboard: sales, revenue, ratings

    Marketplace Pricing Guidelines:

    Strategy Type One-Time Monthly Subscription
    Basic/Starter $499–$999 $99–$199
    Advanced $1,499–$2,999 $299–$499
    Premium/ML $5,000+ $999+

# Submit a strategy for review

    name="Gold Momentum Pro",
    code_path="strategies/gold_momentum.py",

    Subscription Management¶

    from monetization import SubscriptionManager

manager = SubscriptionManager()

# Create new subscription
subscription = manager.create(
    user_id='user_123',
    plan='professional',       # $5,000/month
    billing_cycle='monthly',   # or 'yearly' for 15% discount
    payment_method='card'
)

# Upgrade plan (immediate, prorated)
manager.upgrade(
    subscription_id=subscription.id,
    new_plan='enterprise',     # $10,000/month
    prorate=True               # Credit unused portion of current period
)

# Downgrade plan (effective next billing cycle)
manager.downgrade(
    subscription_id=subscription.id,
    new_plan='starter'         # $2,000/month
)

# Cancel subscription (access until end of paid period)
manager.cancel(
    subscription_id=subscription.id,
    at_period_end=True,
    reason='optional feedback'
)

    License Validation¶

    from monetization import LicenseManager

license_manager = LicenseManager()

# Validate license on startup
is_valid = license_manager.validate(
    license_key='HOPEFX-PRO-XXXX-XXXX-XXXX',
    machine_id=get_machine_id(),
    user_id='user_123'
)

if not is_valid:
    print("Invalid, expired, or unpaid license")
    print("Renew at hopefx.com/billing")

# Check subscription status
status = license_manager.get_status(user_id='user_123')

    Feature Gating¶

    Features are enforced at the API layer:

    from monetization.subscription import require_plan

@router.post("/api/ml/retrain")
@require_plan("enterprise")   # Enterprise only
async def retrain_model(user=Depends(get_current_user)):
    ...

@router.get("/api/ml/predict/{symbol}")
@require_plan("professional")  # Pro and above
async def ml_predict(user=Depends(get_current_user)):
    ...

@router.get("/api/signals/latest")
@require_plan("starter")       # All paid plans
async def get_signal(user=Depends(get_current_user)):
    ...

    Requests exceeding plan limits return 403 Forbidden with error_code: PLAN_LIMIT_EXCEEDED.
